# 🤖 Sarcasm Detection using Sentence Transformers + KNN

This project builds a **sarcasm detection model** using:
- SentenceTransformer embeddings (`all-MiniLM-L6-v2`)
- K-Nearest Neighbors (KNN)
- Twitter dataset (`twitter_training.csv`)

It converts tweets into embeddings and classifies them as:

- 😏 **Sarcastic / Negative**
- 🙂 **Not Sarcastic / Positive**

---

## 🚀 Features
- Clean preprocessing of Twitter dataset  
- Sentence-level embeddings  
- Fast KNN classifier  
- Interactive console-based prediction  
- 80/20 train–test split  
- Classification report + accuracy
